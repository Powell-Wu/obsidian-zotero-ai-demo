# Obsidian + Zotero + AI：公开论文整理演示

一个可独立打开、可离线浏览、可复核证据链的脱敏示例。演示主线是：

**公开论文 → 新建 Zotero 条目与批注 → Obsidian 文献笔记 → AI 两遍整理 → 概念笔记 → 带出处组会大纲**

本 Vault 不依赖第三方 Obsidian 插件；`showcase.html` 不依赖网络、CDN、字体服务或构建工具。

**在线展示：**[打开六步交互演示](https://powell-wu.github.io/obsidian-zotero-ai-demo/) · [查看组会大纲](03综述草稿/组会大纲/数据与模型引导的发射度优化-组会大纲.md) · [核对来源与许可](99附件/来源与许可.md)

## 1. 演示场景

以一篇 European XFEL 的开放获取论文为唯一科学信息来源，演示如何把分散高亮整理为可追溯的知识，而不是让 AI “替论文增加结论”。最终产出一个约 12 分钟的组会大纲；每页科学论述都带有 citekey、PDF 页码与 Evidence Record ID。

- **论文**：H. Tünnermann et al., *Data-model-guided framework for systemic emittance minimization in high-brightness photoinjectors*
- **出处**：Physical Review Accelerators and Beams 29, 050701 (2026)
- **DOI**：[10.1103/kk2s-s43l](https://doi.org/10.1103/kk2s-s43l)
- **citekey**：`tunnermann2026DataModel`
- **阅读深度**：全文级演示，使用出版社 9 页 PDF，不是摘要级伪装精读
- **许可**：[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- **详细来源与校验值**：[[99附件/来源与许可|来源与许可]]

## 2. 三者分工

| 工具 | 负责 | 不负责 |
|---|---|---|
| Zotero | 保存公开题录、PDF、页码高亮和读者评论；维持单篇文献的来源入口 | 不自动判断证据强度，不把读者评论升级为论文结论 |
| Obsidian | 保存文献笔记、概念笔记、证据索引和组会大纲；用 wikilink 保持上下文 | 不替代原文，不让“有双链”等同于“有证据” |
| AI | 第一遍做结构化与证据锚定；第二遍做概念提升、边界约束与写作组织 | 不补造 DOI、实验数值、许可或研究空白，不越过给定全文 |

**AI 两遍的门槛**：第二遍只能使用第一遍已经锚定的证据；新事实必须回到原文补录，不能靠语言流畅度获得可信度。

## 3. 快速开始

### 打开 Vault

1. 在 Obsidian 中选择“打开本地仓库 / Open folder as vault”。
2. 选择本目录，也就是本 `README.md` 所在目录。
3. 从 [[00开始/开始这里|00 开始：开始这里]] 进入，按编号点击即可。
4. 依次查看“AI 整理前”“AI 第一遍”“AI 第二遍”，再进入两篇概念笔记和最终组会大纲。

无需同步账号、第三方插件或个人 Zotero 库。`.obsidian/` 只保存本示例的浅色界面与默认阅读设置。

### 浏览网页

直接双击根目录的 [showcase.html](showcase.html)。页面支持：

- 六步工作流切换与键盘左右键导航；
- AI 整理前、第一遍、第二遍对照；
- 证据边界与原文引句查看；
- 最终组会大纲、打印及本地源文件跳转。

### 查看 Zotero 演示数据

- `demo-data/zotero-item.json`：依据公开元数据新建的 CSL JSON 条目，可作为格式演示。
- `demo-data/zotero-item.bib`：同一 citekey 的 BibTeX 表达。
- `demo-data/zotero-annotations.json`：新建的简化批注数据，不是从任何真实个人库导出。
- `demo-data/zotero-annotations-import.md`：可手工复制到笔记工具的批注导入文本。

批注 JSON 是**教学用简化结构**，不声称是 Zotero 官方可直接导入的 API 备份，也不伪造 PDF 矩形坐标。真实自动化对接时，应按所用 Zotero 版本和插件另行做字段映射。

## 6. 隐私与安全边界

### 本示例包含什么

- 一篇公开论文及其出版社全文；
- 依据论文公开元数据新建的 Zotero 示例条目；
- 由 `Demo Reader (fictional)` 发出的新建批注与评论；
- 本次会话实际生成的 AI 两遍整理文本。

### 本示例不包含什么

- 不读取、不复制任何私人 Vault 笔记正文；
- 不包含真实个人 Zotero 库、真实批注者、订单或未公开工程资料；
- 不写入个人绝对路径、账号、令牌或远端仓库配置；
- 不声称连接了真实 Zotero 客户端或调用了某个本地模型。

### “本地资料”不等于“本地模型”

文件只存在本机，并不表示 AI 推理也只发生在本机。实际处理私人资料前，必须确认所用客户端、插件和模型提供方的数据发送、日志、保留与训练策略；需要离线处理时，应明确选择经验证的本地推理路径。本示例网页本身不发起网络请求，但“在本机打开网页”也不能证明其他 AI 工具没有联网。

论文全文开放并不意味着其实验原始数据开放。论文 PDF 第 8 页明确说明支持结论的数据不公开、可向作者合理申请；本演示没有也不声称拥有这些数据。

## 7. 证据与引用约定

- citekey 始终为 `tunnermann2026DataModel`。
- `ER-01` 至 `ER-06` 是本演示建立的 Evidence Record ID，不是论文原编号。
- `PDF p. N` 按 PDF 文件页序计数，与文内 `050701-N` 一致。
- “作者主张”“演示解读”“读者评论”分开书写。
- `supported` 表示有本文具体实验或仿真支撑，不表示跨装置普遍成立。
- 所有“允许写法 / 禁止更强写法”都是本演示为防止过度外推而加的编辑约束。

## 8. 复核与公开仓库建议

运行离线检查：

```bash
python demo-data/verify_demo.py
```

可选：在本机安装 Edge 或 Chrome 时，重新运行无头浏览器实测。

```bash
node demo-data/browser_smoke.cjs
python demo-data/verify_demo.py
```

浏览器脚本使用本地 CDP，不上传演示内容；它会在 `.tools/browser-profile/` 写入临时浏览器配置，`.tools/` 已由 `.gitignore` 排除，不属于公开示例内容。

检查结果见 [[99附件/验证报告|验证报告]] 与 [[99附件/浏览器验证.json|浏览器实测记录]]。检查覆盖 wikilink、Markdown 本地链接、HTML 本地链接与锚点、网页关键内容一致性、JSON 解析、隐私路径模式及 PDF 校验值；另有 8 项浏览器检查覆盖离线加载、六步切换、AI 对照、证据筛选、大纲展开、桌面与移动布局。
