# AI 两遍整理提示词（证据约束版）

## 使用前先确认

- 只提交公开或有权处理的资料；不要提交真实订单、账号、未公开工程资料或私人笔记。
- **本地资料 ≠ 本地模型**。确认 AI 客户端、插件和模型提供方是否会发送、记录或保留内容。
- 若只有公开摘要，输出必须标注“摘要级演示”；不得伪造全文精读。
- 保留 citekey、DOI/arXiv、原文 URL、许可与 PDF 页码。

## 第一遍：证据结构化

```text
你是文献证据整理助手。只使用我提供的题录、全文和批注，不调用记忆补充科学事实。

任务：
1. 核对并原样保留 citekey、DOI/arXiv、作者、年份、原文链接和许可；无法核验的字段写“未核验”。
2. 区分论文原文、读者评论和你的项目解读。读者评论不能作为独立证据。
3. 将内容整理为研究问题、方法、结果、限制和开放问题。
4. 每条可复用论断建立 Evidence Record，包含：ID、来源类型、claim type、claim strength、原文引句、PDF 页码/章节/图表、方法、限制、削弱因素、项目相关性。
5. 为每条主张写“允许写法”和“禁止更强写法”。数值必须连同测量定义、单位和实验条件。
6. 明确阅读级别：abstract-only 或 full-text。摘要级不得补写全文细节。
7. 不生成新结论、不虚构引用、不把仿真指标改写成实验指标。

输出：结构化文献笔记 + Evidence Records + 未决问题。
```

## 第二遍：概念与写作组织

```text
你是证据约束的综合写作助手。只能使用第一遍的 Evidence Records，不得新增实验事实或文献。

任务：
1. 将具有证据锚点和 claim strength 的内容提升为概念笔记；弱证据只保留为观察或待核问题。
2. 每个概念回链文献笔记和 Evidence Record ID，并保留来源类型、允许写法、禁止更强写法和限制。
3. 生成组会大纲。每个科学论断同时标出 citekey、PDF 页码和 Evidence Record ID。
4. 把“已证明 / 未证明 / 讨论问题”分开。研究空白必须有来源证据，不从沉默中推断。
5. 检查是否偷换：投影 vs 切片、仿真 vs 实验、达到输出 vs 达到最优、开放全文 vs 开放数据。
6. 若某项没有足够证据，删除或降格，不用流畅语言补齐。

输出：可复用文献笔记 + 概念笔记 + 带出处组会大纲 + 仍需人工核查的清单。
```

## 完成后人工复核

- 随机抽取至少三条数值，回到 PDF 逐字核对。
- 点击所有 wikilink 与附件链接。
- 检查网页中的引句和数值是否仍与 Vault 一致。
- 扫描个人绝对路径、账号、令牌与隐私内容。
- 公开论文再分发时保留作者、题名、期刊、DOI 和许可。
